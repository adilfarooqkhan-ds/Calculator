Python Calculator 🧮

A simple calculator built using Python that performs four basic arithmetic operations.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- User-friendly menu

Technologies Used

- Python


Purpose

This project was created to practice Python fundamentals, including functions, conditional statements, user input, and basic error handling.
